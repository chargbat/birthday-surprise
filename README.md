# เว็บไซต์เซอร์ไพรส์วันเกิด — Starlight Over Champagne Sea

ออกแบบด้วยแนวคิด **Warm Editorial Romance × ค่ำคืนริมทะเลและทุ่งหญ้าใต้แสงจันทร์** รองรับการเปิดใช้งานอย่างลื่นไหลบน **โทรศัพท์มือถือ (iPhone / Android)**, **แท็บเล็ต (iPad / Tablet)** และคอมพิวเตอร์

---

## จุดเด่นและลูกเล่นแบบ Interactive (Artisanal Features)

1. **ท้องฟ้ายามค่ำคืน พระจันทร์เต็มดวง แสงสะท้อนผิวน้ำทะเล และหิ่งห้อย (`#starlight-canvas`)**
   - วาดพระจันทร์เรืองแสงพร้อมรัศมีหมอกดาวและเงาแสงจันทร์สะท้อนบนผิวน้ำทะเลที่พริ้วไหวตามคลื่นจริง
   - แตะบนท้องฟ้าเพื่อ **เสกดาวตก (Shooting Stars)** พร้อมประกายละอองดาวและเสียงตัวโน้ตกล่องดนตรีอะคูสติก
   - หิ่งห้อยสีทองและเขียวมรกตลอยขึ้นมาจากทุ่งหญ้าริมทะเลอย่างเป็นธรรมชาติ

2. **เค้กวันเกิดพร้อมเทียนที่อธิษฐานและเป่าดับได้จริง (`#cake-section`)**
   - **วิธีที่ 1 (แตะค้างเพื่ออธิษฐาน):** แตะค้างที่เปลวเทียนหรือปุ่มด้านล่าง วงแหวนคำอธิษฐานจะค่อยๆ เต็มพร้อมเสียงฮาร์ปไล่ระดับโน้ตและการสั่นตอบสนองเบาๆ (Haptic Feedback) เมื่อปล่อยมือเทียนจะดับลง
   - **วิธีที่ 2 (เป่าลมผ่านไมโครโฟน):** กดปุ่มเป่าลมผ่านไมโครโฟน แล้วเป่าลมเข้าที่ไมค์ของมือถือหรือแท็บเล็ตเพื่อดับเทียนจริง
   - เมื่อเทียนดับ จะมีควันเทียนลอยขึ้น โปรยกลีบกุหลาบและแผ่นทองคำเปลว 3 มิติ (`ConfettiEngine`) พร้อมบรรเลงเพลงกล่องดนตรี *Happy Birthday* และเปิดการ์ดคำอวยพร

3. **ซองจดหมายปิดผนึกตราครั่ง (`#letter-section`)**
   - แตะที่ตราครั่งเพื่อเปิดซองอ่านจดหมายอวยพรวันเกิดที่เรียงพิมพ์อย่างประณีตบนกระดาษถนอมสายตา

4. **ดวงดาวคำอวยพรเหนือทุ่งหญ้าและตั๋วของขวัญพิเศษ (`#wishes-section`)**
   - แตะเลือกดวงดาวแต่ละดวงเพื่อเปิดอ่านคำอวยพร โดยดวงดาวดวงที่ 4 จะแสดงผลเป็นคูปองของขวัญขอบปรุสีทองสำหรับแคปหน้าจอเก็บไว้ใช้สิทธิ์

5. **กล่องดนตรีอะคูสติกและเสียงคลื่นทะเล (`SoundEngine`)**
   - สังเคราะห์เสียงกล่องดนตรี (Mechanical Music Box / Celesta) ด้วยการผสมคลื่นเสียง Fundamental + 2nd & 3rd Harmonics คู่กับเสียงคลื่นทะเลเบาๆ โดยไม่ต้องพึ่งไฟล์เสียงภายนอก (หรือสามารถใส่ลิงก์ไฟล์ `.mp3` ของตัวเองได้ใน `config.js`)

## วิธีแก้ไขชื่อและข้อความ (`config.js`)

เปิดไฟล์ [`config.js`](./config.js) ด้วยโปรแกรมแก้ไขข้อความใดก็ได้ (เช่น VS Code, TextEdit, Notepad) แล้วแก้ไขค่าในเครื่องหมายคำพูด `"..."`:

- **`recipientName`**: ชื่อคนพิเศษหรือคำเรียกแทนตัว
- **`senderName`**: ชื่อของคุณที่ลงท้ายจดหมาย
- **`heroSubtitle`**: ข้อความอวยพรสั้นๆ บนหน้าแรก
- **`letter.paragraphs`**: ย่อหน้าข้อความในจดหมายวันเกิด
- **`starWishes`**: คำอวยพรในดวงดาวทั้ง 4 ดวง และข้อความบนตั๋วของขวัญพิเศษ

## วิธีนำเว็บไซต์ขึ้นออนไลน์ฟรี (สำหรับส่งลิงก์หรือทำ QR Code)

1. เข้าเว็บไซต์ **[app.netlify.com/drop](https://app.netlify.com/drop)** บนคอมพิวเตอร์
2. ลากโฟลเดอร์ `birthday-surprise` ทั้งโฟลเดอร์ไปวางในกรอบอัปโหลดบนหน้าเว็บ
3. รอประมาณ 5 วินาที จะได้ลิงก์เว็บไซต์ (`https://...netlify.app`) สามารถคัดลอกลิงก์ส่งทาง LINE หรือแปลงเป็น QR Code ให้คนพิเศษสแกนเปิดบนมือถือและแท็บเล็ตได้ทันที
