# 🎂 เว็บไซต์เซอร์ไพรส์วันเกิด (Starlight Over Champagne Sea)

ออกแบบมาสำหรับการเปิดบน **โทรศัพท์มือถือ (iPhone / Android)** และ **แท็บเล็ต (iPad / Tablet)** โดยเฉพาะ ในโทน **Warm Editorial Romance × ค่ำคืนริมทะเลและทุ่งหญ้าสีเขียวใต้แสงดาว**

---

## ✨ ลูกเล่นภายในเว็บ (Interactive Features)
1. **ท้องฟ้าดาวระยิบระยับ + ทะเลสะท้อนแสงจันทร์ + ทุ่งหญ้าสีเขียวพลิ้วไหว (Hero Panorama)**
   - แตะที่ท้องฟ้าเพื่อ **เสกดาวตก (Shooting Stars)** พร้อมเสียงระฆังดนตรีใสๆ
   - มีหิ่งห้อยแสงสีทองและสีเขียวลอยขึ้นมาจากทุ่งหญ้าริมทะเล
2. **เค้กวันเกิดพร้อมเทียนที่เป่าดับได้จริง (Interactive Birthday Cake)**
   - **วิธีที่ 1 (เสถียรที่สุดบนทุกเครื่อง):** แตะค้างที่เปลวเทียนหรือปุ่มด้านล่างเพื่ออธิษฐาน แล้วปล่อยมือเพื่อเป่าเทียน
   - **วิธีที่ 2 (สนุกขึ้นอีกขั้น):** กดปุ่ม **"เป่าลมผ่านไมค์ 🎙️"** แล้วเป่าลมเข้าที่ไมโครโฟนของมือถือหรือแท็บเล็ตเพื่อดับเทียนจริง
   - เมื่อเทียนดับ จะมีควันเทียนลอยขึ้น พลุกระดาษ (Confetti) โปรยปราย เพลงกล่องดนตรี *Happy Birthday* บรรเลงขึ้น และเปิดการ์ดคำอวยพรพิเศษ
3. **ซองจดหมายปิดผนึกครั่งสีโรสโกลด์ (Wax-Sealed Letter)**
   - แตะที่ตราครั่งรูปหัวใจเพื่อเปิดซองอ่านจดหมายอวยพรวันเกิด
4. **โพลารอยด์ความทรงจำ 3 มิติ (3D Flip Polaroids)**
   - แตะที่รูปโพลารอยด์แต่ละใบเพื่อพลิก 180 องศา อ่านข้อความลับด้านหลังรูป
5. **ดวงดาวคำอวยพรเหนือทุ่งหญ้าและทะเล + ตั๋วตามใจ 1 วัน**
   - แตะเลือกดวงดาวแต่ละดวงเพื่อเปิดอ่านคำอวยพรและคูปองตามใจ 1 วันเต็ม
6. **กล่องดนตรี (Web Audio Music Box + เสียงคลื่นทะเลเบาๆ)**
   - ไม่ต้องกลัวไฟล์เพลงเสีย เพราะตัวเว็บสังเคราะห์เสียงกล่องดนตรีเพลง *Happy Birthday* และเสียงคลื่นทะเลจำลองในตัว (หรือจะใส่ไฟล์ `.mp3` เองก็ได้)

---

## 🛠️ วิธีแก้ไขชื่อ ข้อความ และรูปภาพ (ง่ายมาก ไม่ต้องเขียนโค้ด)

เปิดไฟล์ [`config.js`](./config.js) ด้วยโปรแกรมแก้ไขข้อความใดก็ได้ (เช่น TextEdit, VS Code, Notepad) แล้วแก้ข้อความในเครื่องหมายคำพูด `"..."`:

- **`recipientName`**: เปลี่ยนเป็นชื่อแฟนหรือคำเรียกแทนตัว
- **`senderName`**: ชื่อของคุณที่ลงท้ายจดหมาย
- **`letter.paragraphs`**: แก้ไขย่อหน้าในจดหมายวันเกิด
- **`memories`**: เอารูปคู่ของคุณมาวางในโฟลเดอร์ `birthday-surprise` นี้ (เช่นตั้งชื่อว่า `our-photo1.jpg`) แล้วแก้ `imageUrl: "./our-photo1.jpg"` ได้เลย

## 📱 วิธีเอาเว็บขึ้นออนไลน์ฟรี เพื่อส่งลิงก์ให้แฟนเปิดในมือถือ/แท็บเล็ต

1. เข้าเว็บ **[app.netlify.com/drop](https://app.netlify.com/drop)** บนคอมพิวเตอร์
2. ลากโฟลเดอร์ `birthday-surprise` ทั้งโฟลเดอร์ไปวางในกรอบบนหน้าเว็บ
3. รอประมาณ 5 วินาที จะได้ลิงก์เว็บไซต์ (`https://...netlify.app`) สามารถคัดลอกลิงก์ส่งเข้า LINE หรือทำเป็น QR Code ให้คนรักสแกนเปิดบนแท็บเล็ตและมือถือได้ทันที!
